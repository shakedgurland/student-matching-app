# שידוך בין סטודנטים - אב-טיפוס (Mockup)

אפליקציית התאמות לסטודנטים/ות שמחפשים היכרות אמיתית — בלי אינסוף החלקות, בלי הצפה, ובלי משחקים.

## על הפרויקט
הפרויקט נבנה כחלק מקורס **Vibe Coding**. המטרה היא להציג פתרון לבעיית ה"עומס" באפליקציות ההיכרויות המודרניות על ידי יצירת חוויית משתמש ממוקדת, איכותית ואינטנציונלית יותר.

### רעיון האפליקציה:
- **התאמה אחת בכל פעם**: המשתמש רואה רק מועמד/ת אחד/ת שמתאים/ה לו/ה ביותר.
- **הגבלת כמות**: עד 5 התאמות בחודש לכל היותר.
- **חלון הזדמנויות**: 72 שעות לתחילת שיחה לפני שההתאמה נעלמת.
- **אלגוריתם חכם**: שקלול של ערכים, תחומי לימוד, אורח חיים דתי ושפות אהבה.

## טכנולוגיות
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)
- Google Fonts (Assistant)

## מבנה הקבצים
- `index.html`: המבנה הלוגי של האתר, כולל כל הסקשנים והשאלון.
- `style.css`: עיצוב מודרני, רספונסיבי ותומך RTL מלא.
- `script.js`: לוגיקה של השאלון הרב-שלבי, תצוגה מקדימה של תמונות וניהול אירועים.

## הוראות הפעלה
פשוט פתחו את הקובץ `index.html` בכל דפדפן מודרני. אין צורך בשרת או בהתקנות נוספות.
